# 🌍 Protocol 13 — SDG 13 氣候行動互動網站

> 把冰冷的氣候數據，變成一個你會想動手玩、而且「跟你有關」的互動體驗。

一個以**工業科幻監控終端**為設計風格的單頁網站，主題為聯合國永續發展目標 **SDG 13：氣候行動 (Climate Action)**。網頁程式設計期末專題（個人獨立完成）。

## 🎯 設計理念

氣候變遷最大的傳播困難，往往不是大家不相信，而是它「感覺很遙遠」。本網站的核心理念，是把抽象遙遠的氣候危機，轉化成**與使用者自身城市有關**的個人化體驗，並透過「監控終端」的沉浸式視覺，讓接觸氣候資料像在操作系統、而非閱讀報告。

整體目標是一條情感動線：**從「覺得遙遠」→「覺得與我有關」→「我能做點什麼」。**

## ✨ 主要功能

- **即時氣候掃描器** — 串接 OpenWeatherMap API，查詢任何城市的即時氣溫與空氣品質 (AQI)
- **你的城市，2050** — 用真實 CMIP6 氣候模型推估你家未來的高溫日、年均溫變化，並用 Climate Central 把海平面上升的**淹水範圍疊在街道地圖上**（可切換「現況 ↔ 2100」對比）
- **淨零排放模擬器** — 互動式升溫曲線圖（Chart.js），在 IPCC SSP 情境間即時內插；選項效果隱藏、選錯會跳警告，引導使用者「自己試出」減碳必須多管齊下
- **氣候知識檢測** — 邊答題邊學的氣候素養測驗
- **臨界警報系統 / 系統日誌** — 沉浸式的監控終端體驗

## 🎓 SDGs 學習成效（SDG 13.3：氣候教育與意識提升）

使用者瀏覽後可以：
- 認識 CO₂ 濃度、全球升溫、海平面上升等關鍵指標
- 理解《巴黎協定》1.5°C 目標的意義
- 體會「減碳沒有單一萬靈丹，必須多管齊下」
- 感受氣候變遷與自己居住城市的直接關聯

## 🛠️ 使用工具與技術

- **前端**：HTML / CSS / JavaScript（純手刻，無框架）
- **視覺化**：[Chart.js](https://www.chartjs.org/) — 升溫曲線圖
- **真實資料 API**：[OpenWeatherMap](https://openweathermap.org/api)（即時天氣）、[Open-Meteo Climate API](https://open-meteo.com/)（CMIP6 降尺度氣候推估）
- **嵌入服務**：[Climate Central](https://coastal.climatecentral.org/)（海平面淹水地圖）
- **部署**：Git / GitHub Pages
- **AI 工具**：開發過程使用 Claude (Claude Code) 輔助撰寫與除錯程式碼、討論技術取捨

## 🧩 工程決策與挑戰

> 這個專案我比較在意的不是「做了多少功能」，而是過程中的判斷。

- **淹水地圖：以可信度為優先** — 原本想自己用地形高程資料計算淹水，但考量準確度與公信力，改為嵌入經同行評審、發表於 *Nature Communications* 的 Climate Central 模型。
- **iframe 水位無法切換** — 切換年份時地圖沒反應，查出是「只改網址 hash 不會重新載入」，改用強制重載（`about:blank` → 新網址）解決；並發現必須帶 `projections` 參數，地圖才會顯示水位。
- **資料門檻的誠實調整** — CMIP6 模式對台北每日最高溫偏保守，>35°C 天數極少；改用國際認可的 >33°C 熱壓力門檻，數據既真實又有意義，並在圖上標明哪些是 IPCC 官方值、哪些是視覺化內插。
