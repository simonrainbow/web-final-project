SDG 13.1 // RESILIENCE
強化氣候韌性與適應力
目標 13.1 要求各國加強對氣候相關危害和自然災害的抵禦能力。具體行動包括：
  • 建立早期預警系統，及時通知沿海和脆弱地區居民
  • 制定完整的防災計畫，特別針對洪水、乾旱和極端天氣
  • 加強基礎設施的氣候韌性設計標準
  • 投資自然解決方案，如紅樹林和濕地保護
STATUS: 全球已有 120+ 個國家建立國家適應計畫（NAPs）
SDG 13.2 // POLICY
整合氣候變化政策
各國必須將氣候行動整合至核心政策框架中，確保政策一致性：
  • 設定具法律約束力的碳中和時間表（台灣 2050 淨零目標）
  • 推動碳交易市場與碳稅機制
  • 將氣候風險納入金融監管體系
  • 要求企業揭露氣候相關財務風險（TCFD）
STATUS: 台灣已通過《氣候變遷因應法》，設定 2050 淨零排放目標
SDG 13.3 // EDUCATION
氣候教育與意識提升
教育是應對氣候危機最有力的工具之一，本網站即是此精神的實踐：
  • 在學校課程中融入氣候教育內容
  • 利用數位工具與互動設計提升氣候意識（如本網站）
  • 培訓社區領袖成為氣候行動倡導者
  • 利用媒體和社群平台擴大氣候行動訊息
STATUS: 本專題即為 SDG 13.3 的具體實踐 — 透過科技讓氣候議題更具吸引力
SDG 13.A // FINANCE
綠色氣候基金
氣候融資是落實 SDG 13 的關鍵，已開發國家須承擔歷史排放責任：
  • 每年 1,000 億美元目標 — 資金用於最脆弱國家的氣候適應
  • 綠色氣候基金（GCF）已核准超過 400 個氣候項目
  • 推動私部門投資轉向低碳清潔能源
  • 2022 年全球氣候融資達 8,910 億美元
STATUS: 氣候融資規模仍不足實際需求的 1/6，需大幅加速
SDG 13.B // CAPACITY
提升開發中國家能力
最脆弱的國家往往排放最少卻受影響最大，必須優先獲得支援：
  • 最低度開發國家（LDCs）和小島嶼國家（SIDS）優先獲得技術支援
  • 轉移清潔能源技術，協助跳過化石燃料依賴階段
  • 加強氣象預報能力，改善早期預警系統
  • 建立南南合作機制，分享氣候適應最佳實踐
STATUS: 超過 48 個最低度開發國家已提交國家自主貢獻（NDCs）
PARIS AGREEMENT // GLOBAL COMMITMENT
巴黎協定
2015 年 12 月通過的巴黎協定是人類史上最重要的氣候協議：
  • 195 個締約方承諾將升溫控制在 2°C 以下
  • 努力將升溫限制在工業化前水準 1.5°C 以內
  • 每個國家須定期提交和更新「國家自主貢獻（NDC）」
  • 每 5 年進行一次全球盤點，檢視進展
STATUS: 目前各國 NDCs 若全部實現，預計升溫約 2.5°C — 仍須大幅加強行動

⚠ WARNING // 高排放行為警告
這是錯誤的選擇！
擴建燃煤電廠
你剛剛選擇的是「高排放行為」 — 它會排放大量溫室氣體，加速全球升溫，讓地球離 1.5°C 目標越來越遠。如果人類持續這類行為，將造成：
  • 🌊 海平面大幅上升，沿海城市與島國被淹沒
  • 🔥 致命熱浪、野火、乾旱成為常態
  • 🐠 超過 99% 珊瑚礁死亡，生態系崩潰
  • 🌾 全球糧食與水資源嚴重短缺
✓ 正確做法：取消這個行為，改為選擇再生能源、電動運輸、造林、碳捕捉等減碳行動，才能把升溫壓回 1.5°C 目標以內。
